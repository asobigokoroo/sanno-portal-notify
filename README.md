# sanno-portal-notify

産業能率大学ポータルのお知らせを自動監視し、新しい情報だけをDiscordへ届ける通知ツールです。GitHub Actions上で定期的に実行するため、パソコンを起動していない時間帯でもポータルを確認できます。

## このツールでできること

- ポータルへBasic認証でログインし、「お知らせ」一覧を自動取得
- 一覧を複数ページ確認し、最大200件の表示に切り替えて新着を取りこぼしにくくする
- タイトルをもとにお知らせを識別し、通知済みの情報を重複送信しない
- 「重要」「休講」「注目」のタグを判定し、Discord通知の色や絵文字で見分けやすく表示
- 新着が1〜2件の場合は個別通知、新着が3件以上の場合は一覧形式のまとめ通知
- Discord Embedに実際の送信時刻を設定し、通知を受け取った時刻を確認可能
- 通信失敗時は最大3回、待ち時間を伸ばしながら再送
- 通知履歴を`seen.json`に保存し、GitHub Actionsが次回実行へ引き継ぐ

## 通知の流れ

1. GitHub Actionsがポータルへアクセスします。
2. ポータルのお知らせ一覧からタイトル、日時などの情報とリンクを取得します。
3. `seen.json`に記録されていないお知らせだけを新着として判定します。
4. 新着情報をDiscord Webhookへ送信します。
5. 通知済みのお知らせの識別情報を`seen.json`へ保存し、リポジトリへコミットします。

初回実行時は、既存のお知らせを通知せずに基準として登録します。これにより、監視開始時に過去のお知らせが大量送信されることを防ぎます。

## Discord通知の見え方

新着が2件以下の場合は、お知らせごとにタイトル、ポータルへのリンク、取得したメタ情報を含むEmbedを送信します。新着が3件以上ある場合は、複数のお知らせを1つのEmbedにまとめ、通知数と各お知らせへのリンクを一覧表示します。

タイトルに次のキーワードが含まれる場合は、通知を分類して表示します。

| 分類 | 表示 |
| --- | --- |
| 重要 | 赤色、警告アイコン |
| 休講 | オレンジ色、休講アイコン |
| 注目 | 紫色、注目アイコン |
| その他の新着 | 緑色、新着アイコン |

各Embedには送信時刻が付くため、Discordの表示設定に応じた時刻で通知されたタイミングを確認できます。Discordへの送信に失敗した場合は、すぐに終了せず、最大3回まで再送します。

## 履歴と重複通知の防止

お知らせのタイトルから識別情報を作成し、`seen.json`へ保存します。次回以降の実行では、この履歴と現在のお知らせを比較することで、同じお知らせを何度も通知しないようにします。履歴は最大2,000件まで保持します。

ポータル側で同じタイトルのお知らせが複数表示される場合は、同一のお知らせとして扱います。タイトルが変更された場合は別のお知らせとして判定されるため、必要に応じて履歴を確認してください。

## 自動実行のタイミング

GitHub ActionsのスケジュールはUTC基準で、毎時00分と30分に設定しています。日本時間でも毎時00分と30分です。ただし、GitHub Actionsの混雑状況によって実際のジョブ開始が数分遅れることがあります。指定時刻は実行開始の目安であり、秒単位の実行を保証するものではありません。

Actionsの **SANNOポータル通知 > Run workflow** から手動実行することもできます。

## 必要なSecrets

リポジトリの **Settings > Secrets and variables > Actions** に次のSecretsを登録してください。

| Secret | 内容 |
| --- | --- |
| `SANNO_ID` | ポータルのログインID |
| `SANNO_PASS` | ポータルのパスワード |
| `DISCORD_WEBHOOK` | Discord Webhook URL。複数指定時はカンマ区切り |

認証情報とWebhook URLはソースコードや`README.md`へ直接書き込まず、必ずGitHub Secretsで管理してください。

## ローカル実行

```bash
pip install -r requirements.txt
playwright install chromium

SANNO_ID="..." \
SANNO_PASS="..." \
DISCORD_WEBHOOK="..." \
python portal_notify.py
```

ローカル実行では、実行環境にPlaywrightとChromiumがインストールされている必要があります。`seen.json`は通知履歴を兼ねるため、動作確認後に削除すると、次回実行時に初回実行として扱われます。
